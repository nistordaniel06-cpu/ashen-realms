# Ashen Realms V1

Phaser 3 + TypeScript + Vite isometric browser RPG prototype.

## Run

```bash
npm install
npm run dev
```

Build with `npm run build`.

## Controls

WASD/arrows or click to move; mobile joystick; SPACE/ATAC to attack; E/NPC to talk. Defeat three wolves and return to the guardian.

## Status

V1 is single-player, without persistence or multiplayer. GitHub Pages workflow is included; enable Pages source **GitHub Actions** in Settings > Pages. No verified production build yet.
